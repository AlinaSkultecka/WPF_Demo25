# WPF_Demo25

**WPF_Demo25** is a simple Windows Presentation Foundation (WPF) application demonstrating a **basic layout using Grid panels**. The application shows how to structure a window into header, content, and footer sections with different background colors.

---

## Features

- **Grid layout** with rows and columns
- **Header**, **content**, and **footer** sections
- Basic styling using `Rectangle` elements for visual separation
- Placeholder layout for future content and controls
